🔬 TM Lifetime Analyzer

Advanced Multilevel ODE Fitting for Yb³⁺/Tm³⁺ Upconversion Dynamics

📖 Project Overview

This is a PhD-level research tool for analyzing photoluminescence lifetime decay curves in rare-earth doped upconversion materials. The analyzer uses a comprehensive 9-state energy level model to fit experimental time-resolved emission data and extract fundamental photophysical parameters including energy transfer rates, radiative lifetimes, and non-radiative decay pathways.

The system solves coupled ordinary differential equations (ODEs) describing population dynamics across Yb³⁺ and Tm³⁺ energy levels under 980 nm laser excitation, capturing complex processes such as energy transfer upconversion (ETU), cross-relaxation (CR), and multiphonon relaxation.

⚡ Key Features

  • ✓ Multilevel ODE solver (9-state model)
  • ✓ Energy transfer rate extraction
  • ✓ Phonon-assisted decay modeling
  • ✓ Batch analysis for multiple datasets
  • ✓ Interactive parameter optimization
  • ✓ Real-time physics visualization

🎯 Target Emissions

  • 📍 1800 nm - ³F₄ NIR (Metastable)
  • 📍 775 nm - ³H₄ NIR
  • 📍 645 nm - ¹G₄ Red
  • 📍 477 nm - ¹G₄ Blue
  • 📍 452 nm - ¹D₂ Blue/Violet
  • 📍 362 nm - ¹D₂ UV
  • 📍 345 nm - ¹I₆ UV (Top Tier)

🔬 Scientific Foundation

Physics Model: The analyzer implements rate equation analysis based on energy transfer mechanisms in lanthanide-doped systems. It accounts for sequential ETU processes (Yb³⁺ → Tm³⁺), back transfer, cross-relaxation between Tm³⁺ ions, and phonon-mediated non-radiative decay following the energy gap law: Wnr = C·exp(-α·ΔE/ℏω).

🚀 Getting Started

  1. Navigate to Lifetime Analyzer: Click the "🔬 Lifetime Analyzer" button in the sidebar
  2. Upload Data: Load your CSV/JSON lifetime decay data (time vs intensity)
  3. Configure Parameters: Set doping levels, host material, emission wavelength, and measurement settings
  4. Set Physics Constants: Define phonon energy and choose NR mode in order: `fit` → `theoretical` → `anchor` → `manual`
  5. Run Analysis: Click "FIT MY DATA" to extract rate constants and visualize results
  6. Batch Processing: Upload multiple files for automated comparative analysis

    🚀 Quick Start Guide

    1. Navigate to Lifetime Analyzer: Click "🔬 Lifetime Analyzer" in the sidebar
    2. Upload Your Data: Click or drag-and-drop CSV/JSON files containing time vs intensity data
    3. Configure Parameters: Set Yb/Tm doping levels, host material, and emission wavelength

    🔧 Troubleshooting Common Issues

    ❌ Error: "Address already in use" (Port 5000)

    Cause: Another Flask instance is running or port is occupied

    Solution 1 - Kill the process:

    Windows:
    netstat -ano | findstr :5000
    taskkill /PID <PID_NUMBER> /F

    Mac/Linux:
    lsof -i :5000
    kill -9 <PID_NUMBER>

    Solution 2 - Change port: Edit app.py and change port to 5001 or another available port

    ❌ Error: "No module named 'flask'" or similar import errors

    Cause: Required packages not installed

    Solution:

    pip install flask numpy scipy matplotlib
    Or install from requirements.txt:
    python3 -m pip install -r requirements.txt

    ❌ File Upload Not Working

    Cause: Browser compatibility or JavaScript not loaded

    Solutions:

    • Refresh the page (Ctrl+F5 or Cmd+Shift+R)
    • Clear browser cache
    • Try a different browser (Chrome, Firefox, Edge recommended)
    • Check browser console for errors (F12 → Console tab)
    • Ensure JavaScript is enabled in browser settings

    ❌ Fitting Fails or Returns Poor Results (Low R²)

    Possible Causes & Solutions:

    • Wrong time units: Ensure your data time units match the selected units (ns/μs/ms)
    • Noisy data: Try smoothing or averaging multiple measurements
    • Wrong emission wavelength: Double-check you selected the correct transition
    • Physics parameters: Verify phonon energy and doping concentrations are correct
    • Configuration not applied: Click "Apply & Configure Solver" before fitting

    🧭 Dominant Error Region Remedies (Troubleshooting Panel)

    When Troubleshooting reports a dominant region, use these remedies:

    • Peak window dominant: In single mode, click Try this in Single: Enhance Peak Window or enable single-channel peak enhancement in Advanced settings.
    • Early rise dominant: In single mode, click Try this in Single: Enhance Early Rise or enable single-channel early-rise enhancement in Advanced settings.
    • Time offset (t0) is different: Use time offset only for fixed trigger/start delay; use early-rise enhancement when the early shape itself is mismatched.
    • Practical order for early-rise cases: Keep early-rise checkbox OFF first, tune pulse width + time offset, then turn checkbox ON only if mismatch remains.
    • Tail dominant: Improve baseline correction and verify long-time SNR before increasing fit complexity.
    • General rule: Apply the single-channel remedy first, then return to multi-channel sequence when the channel is stable.
    New: Multi-channel mode now performs automatic error-code-driven retries (FIT-E11/E12/E13/E21, with legacy FIT-E01/E02/E03/E04 support), including stricter 775 early-rise correction and timing-mismatch recovery for 345/362, so manual single-channel pre-fit is usually not required.

    Error codes used in troubleshooting output:

    • FIT-E00: Target R² not reached (global quality gap)
    • FIT-E11 (legacy FIT-E01): Early-rise dominant mismatch (check pulse width and T_offset first)
    • FIT-E12 (legacy FIT-E02): Peak-window dominant mismatch (check apex weighting/saturation)
    • FIT-E13 (legacy FIT-E03): Tail dominant mismatch (check baseline and late-time SNR)
    • FIT-E21 (legacy FIT-E04): R² looks acceptable, but timing alignment is still poor (rise/peak/decay timing mismatch)
    • FIT-E31: Host/annealing influence likely dominates; revisit host mole factor, lattice energy, and annealing assumptions.

    💡 Frequently Asked Questions

    Q: What is the Recirculation Efficiency (Rf)?

    A: Recirculation Efficiency shows the ratio of population returning to ³F₄ level vs. being lost to ground state. Higher values (>60%) indicate efficient energy recycling through the ¹G₄ → ³F₄ pathway, which explains long rise times in blue emission at high Tm concentrations.

    Q: How do I interpret the ODE equations displayed?

    A: The ODE panel shows the differential equation being solved for your selected emission. Population terms (+) show how ions enter the state (via energy transfer), while depopulation terms (-) show how they leave (radiative decay, non-radiative losses).

    Q: Can I fit multiple files at once?

    A: Yes! Upload multiple files or an entire folder. The batch analysis panel will appear, allowing you to fit all files sequentially with the same parameters.

    Q: What does "Anchor Mode" mean for non-radiative decay?

    A: Anchor Mode calculates Wnr directly from experimental lifetime data instead of using theoretical phonon energy. Input your measured ³H₄ lifetime (775nm) as τexp and the theoretical radiative lifetime as τrad.

    Q: What does "Manual (Expose all NR inputs)" mean?

    A: It means all non-radiative (NR) controls are shown at once: theoretical constants (C, alpha) plus anchor lifetimes (Primary τexp, Optional Feeding τexp, and τrad). Use Manual only after trying fit/theoretical/anchor, and only when you need full custom tuning.

    Q: Why is rise time reported as 10-90% instead of 0-100%?

    A: The analyzer reports rise time from 10% to 90% of the peak because 0% and 100% are usually unstable in real transient data. The baseline near 0% is affected by noise, drift, smoothing, and time-zero uncertainty, while the exact 100% peak is sensitive to sampling resolution, saturation, and single-point spikes. Using 10-90% gives a more repeatable measure of the physically meaningful rising edge.

    Rise time (10-90) = t(I = 0.9·I_peak) - t(I = 0.1·I_peak)

    Q: What does Decay τ (1/e) mean, and how is it different from A50?

    A: Decay τ (1/e) is a measured metric — the time after the peak at which the intensity falls to 1/e ≈ 36.8% of the peak value. Yes: decay timing starts from the peak time, so the reference time is t_peak (the moment the peak turns over and begins to decline). It is extracted from the trace after fitting and captures the effective depopulation rate of the observed level. It is not a fit parameter; it is computed from the final simulated curve.

    Decay tau (1/e) = t(I = I_peak/e) - t_peak

    A50 is a kinetic rate parameter in the ODE — the spontaneous radiative decay rate of the ³H₄ level (Tm₅) to the ground state (units: ms⁻¹). If ³H₄ depopulated only by radiation, the lifetime would simply be 1/A50. In reality, multiple processes drain ³H₄ simultaneously:

    1/τobs ≈ A50 + Wcr·[Tm₀] + W3·[Ybe] + Wb·[Ybg]

    Because of cross-relaxation (Wcr), upward energy transfer (W3), and back-transfer (Wb), the observable τ is always shorter than 1/A50. At higher Tm%, Wcr dominates and τ shrinks dramatically. A50 alone represents the intrinsic radiative lifetime — what you would measure in a perfectly isolated, non-interacting Tm ion with no energy transfer partners.

    Q: What is Peak Time, and what does Peak Time Error mean?

    A: Peak Time is the time coordinate where the intensity reaches its maximum value on the curve (time at max intensity). Peak Time Error is the absolute difference between measured peak time and fitted peak time. You can see both in Timing Metrics as Measured Peak Time and Fitted Peak Time. A smaller error means the model peak occurs closer to the experiment.

    Peak time = argmax_t I(t)
    Peak time error = |t_peak,fitted - t_peak,measured|
